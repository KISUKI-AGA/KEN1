# 計畫通用布條（拍照用）

教育部實作場域設備精進計畫「AI 賦能與韌性產業升級：智慧工安、永續能源與卓越製造之跨域整合培育計畫」通用布條。
不含日期與活動名稱，開會、授課、工作坊、企業訪視皆可共用；三場域、各協辦單位輪流使用。

| 檔案 | 用途 |
|---|---|
| `布條_300x90cm_印刷用.pdf` | 交印刷廠，實際尺寸 300 × 90 cm，向量文字、字型已內嵌 |
| `布條_預覽.png` | 預覽、傳 LINE 確認用（6000 × 1800 px） |
| `design-philosophy.md` | 設計理念 |

## 交印刷廠時請註明

- 材質：**霧面**帆布或無光布（避免閃光燈反光）
- 四角與上下緣每 50 cm 打鐵環（設計已預留四角空白）
- 出血由印刷廠於四周外擴 3–5 cm 底色
- 如需加校徽或教育部標誌，請放在兩側圓環圖形位置，勿壓到文字

## 拍照時

- 布條下緣離地約 1.9–2.0 m，站在前排的人才不會擋到最下面的單位名稱
- 拍攝時布條約佔畫面寬度 6 成以上，三行文字皆可辨識
- 活動名稱用 A3 立牌另外放在前方，例如「月度聯席會議」「業師協同教學｜○○課程」「AI 電池診斷工作坊」「產學合作訪視｜○○公司」
